# 融酒 · 本地调酒助手

一个**纯静态网页**的调酒配方应用，同时也是一个**可安装到手机的 PWA**：装到主屏幕后是全屏、有图标、能离线用的独立 App。
**不联网、不登录、不装软件、不需要服务器**，配方库随项目走，个人数据只存在本机浏览器里。

界面按手机屏幕尺寸设计（`.phone` 容器最大宽 420px），在电脑浏览器里就是一个居中的手机框，在手机上打开就是 App 的样子。

> 需求与决策的完整记录见 [PRO.md](./PRO.md)，本 README 只描述**当前实际功能**。

---

## 1. 项目解决什么问题

想在家调一杯酒，通常会卡在三件事上：

| 痛点 | 融酒怎么做 |
| --- | --- |
| 配方散落在网站、短视频、收藏夹里，想找一杯要翻半天 | 内置 **1341 条**配方（**1340 张实拍图**），按 10 个分区铺成「横向货架」，像刷视频一样左右逛 |
| 看中一款，结果家里材料不够，白高兴一场 | 酒柜页录入手头材料，自动列出**现在就能做的酒**，以及**还差哪一样** |
| 选择困难，翻来翻去定不下来 | 盲盒页按价格档位 + 口感 + 酒精筛一遍，点一下随机给一瓶，可「再来一次」 |

配套解决「数据放哪」的问题：不登录、不上传，酒柜 / 材料 / 评分 / 历史 / 自制配方全部存在浏览器本地（`localStorage`），刷新、关浏览器、重启电脑都不丢，并支持**导出成 JSON 文件备份 / 导入还原**。

## 2. 主要功能

### 底部三栏导航

`🍸 推荐` · `🗄 酒柜` · `🎁 盲盒`，右上角 ⚙ 进设置。

### 推荐页（默认首页）

- **横向分区货架**：每款酒只进一个区，按优先级互斥归类，共 10 个分区：

  | 分区 | 数量 |
  | --- | --- |
  | 中国饮料兑酒 | 36 |
  | 一口闷 Shot | 74 |
  | 无酒精特调 | 271 |
  | 咖啡与茶 | 27 |
  | 伏特加调酒 | 211 |
  | 金酒调酒 | 155 |
  | 朗姆调酒 | 157 |
  | 威士忌调酒 | 100 |
  | 龙舌兰调酒 | 53 |
  | 经典鸡尾酒（兜底） | 257 |

  自制配方单独一排「我的自制」置顶。
- **进分区看全部**：分区右侧「全部 N ›」进入该分区完整列表（URL 变成 `#/recommend?sec=vodka`），顶部「← 全部」返回货架。
- **浏览全部入口**：搜索框正下方的「浏览全部配方 · 1341 款」，不用滑到底。
- **筛选条**：口味（9 类，可多选）/ 材料（60 个高频材料，可多选）/ 酒精强度（不限 · 无酒精 · 低度 · 高度）；搜索或筛选时货架自动切换成纵向卡片列表。
- **搜索**：任一字命中即保留（输入「莫托」也能找到「莫吉托」）；**酒名里出现完整查询串的排最前**，其次按命中字数降序。
- **无限加载**：每次 30 条，滑到底自动追加下一批（同一列表内不重复），也可点「加载更多」。
- **🔄 换一批**：重新打散顺序并回到顶部。
- **卡片信息**：图片、酒名、分类、酒精、价格估算、口味摘要（最多 2 个，多的显示 `+N`）、`＋ 加入酒柜`；打过星的显示 `已喝过 ★N`，自制的显示 `自制`。

### 详情页

大图 + 酒名 + 信息标签（分类 / 酒精 / 杯型 / 估价与档位 / 口味）→ 配料 → 做法 → 做法（英文原文，弱化显示）→ **我的评价**（点 1~5 星，再点同一颗星取消）→ `＋ 加入酒柜` / `✓ 已在酒柜 · 点击移除`；自制配方多一个「删除」。
直接打开或刷新详情页 URL 也会记入浏览历史。

### 酒柜页

- **我的材料**：录入手头配料，支持**一次填多个**、**英文自动转中文**、带单位也能识别；输入框下方常驻「常见材料」建议区（24 个，点一下直接加，打字时实时按关键词过滤）。
- **能做的酒**：`材料齐全` 与 `还差 1 样` 两组，缺的那一样会标在卡片上（差 2 样以上的不列出）。
- **我的酒柜**：收藏的配方，可移除、可进详情。
- **喝过的酒**：打过星的酒，按星级从高到低。
- **浏览历史 · N 条**：进入浏览历史页。

### 浏览历史页

地址 `#/history`，从酒柜页进入。打开过的酒按时间倒序，每条显示 `2026年10月08日 20点31分`，可单条删除 ✕，也可整体「清空历史」；**最多保留 100 条**；空态有「去逛逛」引导。

### 盲盒页

- **价格档位**：默认**不限**（一个都不选 = 不限），点选一个或多个档位就只看这些档；档位名称与价格区间可在设置里自定义，最高价留空表示不限。
- **想要的口感**：9 类多选，命中任一所选标签即可入池。
- **酒精**：不限 / 含酒精 / 无酒精。
- 实时显示 `符合条件：N 款`，点「🎯 抽一瓶」随机出一瓶，结果卡可直接 `加入酒柜` 或 `🎲 再来一次`（不会连续抽到同一瓶）。

### 设置

| 入口 | 说明 |
| --- | --- |
| ＋ 新增配方 | 名称、分类、是否含酒精、杯型、配料（每行一条）、做法、**照片（可选）**；照片会自动压缩到 640px / JPEG，存进浏览器本地，刷新后仍在 |
| ⬇ 导出备份 | 下载 `融酒备份-YYYY-MM-DD.json` |
| ⬆ 导入备份 | 选择 `.json` 备份，可选**合并导入**或**覆盖导入** |
| ¥ 价格档位 | 增删改价格档位（名称 + 最低价 + 最高价），最高价留空 = 不限；空名称会明确报错，不会静默丢弃 |
| ⓘ 关于 | 项目说明 |
| 🗑 清空全部数据 | 清空**酒柜 / 自制 / 材料 / 评分 / 历史**（有应用内确认弹层，二次确认后才执行） |

### 数据与本地存储

配方库共 **1341 条**，来源前缀 `tcdb-`(628) · `od-`(666) · `cn-`(36，中国饮料兑酒) · `dy-`(11，短视频酒谱)；自制配方为 `my-` 前缀。
个人数据存于浏览器 `localStorage`：

| 键 | 内容 |
| --- | --- |
| `rj.cabinet` | 酒柜（配方 id 数组） |
| `rj.custom` | 自制配方（含压缩后的照片 dataURL） |
| `rj.pantry` | 我的材料 |
| `rj.ratings` | 星级评价 |
| `rj.history` | 浏览历史（最多 100 条） |
| `rj.settings` | 价格档位等设置（`priceTiers`） |

### 装成手机 App（PWA）

项目带 `manifest.webmanifest` + `sw.js`（Service Worker）+ 应用图标，所以它可以直接**安装到手机主屏幕**，装完就是一个独立 App：

- 全屏运行，**不显示浏览器地址栏**（`display: standalone`）；
- 主屏幕上有自己的图标名「融酒」；
- **离线可用**：App 外壳（HTML/CSS/JS 共约 1.4 MB）首次打开就预缓存；配方图片看一张存一张（最多留 240 张，超出丢最早的），没网时已经看过的图照样能显示；
- 顶部状态栏按品牌色 `#b4642a` 着色，并已处理刘海与底部手势条的安全区。

安装方式：

| 平台 | 操作 |
| --- | --- |
| Android（Chrome / Edge） | 打开网页 → 右上角菜单 → **「安装应用」/「添加到主屏幕」** |
| iOS（Safari） | 打开网页 → 底部「分享」按钮 → **「添加到主屏幕」** |
| 桌面 Chrome / Edge | 地址栏右侧出现「安装」图标，点一下就是一个独立窗口的 App |

> ⚠️ Service Worker 只在 **https 或 localhost** 下生效。直接双击 `index.html`（`file://`）时 App 功能完全正常，只是没有离线缓存。
> 线上地址见下面「安装方法」。

## 3. 安装方法

**不需要安装任何东西，也不需要联网。** 运行 App 只需要一个浏览器（推荐 Chrome / Edge）。

### 方式一：直接打开线上地址（手机上推荐，能装成 App）

**https://myayy.github.io/rongjiu/**

手机浏览器打开后用「添加到主屏幕」（见上一节），即可获得全屏、离线可用的独立 App。
（该地址由本仓库的 GitHub Pages 提供，页面壳和图片走网络，你的酒柜 / 材料 / 评分等数据始终只存在你自己手机里。）

### 方式二：下载到本地用浏览器打开（最简单、完全离线）

1. 下载或克隆本仓库到本地；
2. **保留整个目录结构**（`素材/` 约 74 MB 必须一起下载，否则图片显示不出来）；
3. 双击根目录的 `index.html`，浏览器即可打开使用。

### 方式三：起一个本地静态服务器（可选）

`file://` 下 Service Worker 无法注册，体验不到离线缓存；用静态服务器打开就能完整跑 PWA。任意静态服务器指向项目根目录即可，例如：

```bash
npx serve .          # 然后访问 http://localhost:3000/index.html
```

### 只有跑测试才需要 Node.js（开发用，运行 App 不需要）

需要 Node.js 18+（用到内置的 `node --test`），无需 `npm install`——项目零依赖。

## 4. 使用方法

### 逛与收藏

1. 打开 App 默认落在**推荐页**，左右滑动各分区，点卡片看详情；
2. 详情页点 `＋ 加入酒柜` 收藏，点 `★` 打分（再点同一颗取消）；
3. 想看某个分区的全部，点分区右侧「全部 N ›」，返回点左上角「← 全部」；
4. 想按条件挑，直接在搜索框输入酒名或材料，或用下面的口味 / 材料 / 酒精强度筛选。

### 用「我的材料」找现在能做的酒

1. 底部切到**酒柜**，在「我的材料」输入框里填家里现有的配料（冰块和水不用填），点 `＋` 或回车；
2. 下方「能做的酒」会立刻分组显示：
   - `材料齐全`：现在就能做；
   - `还差 1 样`：只差一样，卡片上会标出缺的是什么；
3. 也可以直接点「常见材料」里的胶囊快速添加。

### 用盲盒决定喝什么

1. 底部切到**盲盒**，按需点价格档位（不点 = 不限）、口感、酒精；
2. 看 `符合条件：N 款`，点 `🎯 抽一瓶`；
3. 不满意点 `🎲 再来一次`，满意点 `＋ 加入酒柜`。

### 加入自己的配方

1. 右上角 ⚙ → `＋ 新增配方`；
2. 填名称（必填）和配料（必填，每行一条），可选分类、杯型、是否有酒精、做法、照片；
3. 保存后立刻出现在推荐页最前面的「我的自制」，刷新后仍在。

### 备份与迁移

1. ⚙ → `⬇ 导出备份`，下载 `融酒备份-2026-10-08.json`；
2. 换设备或换浏览器时，⚙ → `⬆ 导入备份`，选择该文件即可（`合并导入` 保留现有数据，`覆盖导入` 用备份完全替换）。

### 常用地址（可直接收藏 / 分享）

| 地址 | 页面 |
| --- | --- |
| `#/recommend` | 推荐页（货架首页） |
| `#/recommend?sec=all` | 浏览全部配方 |
| `#/recommend?sec=vodka` | 某个分区（`mixer`/`shot`/`mocktail`/`coffee`/`vodka`/`gin`/`rum`/`whisky`/`tequila`/`classic`/`mine`） |
| `#/recommend?q=莫吉托` | 带搜索词的推荐页 |
| `#/drink/cn-016` | 某条配方的详情页 |
| `#/cabinet` | 酒柜页 |
| `#/history` | 浏览历史页 |
| `#/box` | 盲盒页 |

## 5. 输入输出实例

### 例 1：搜索「莫吉托」

**输入**：在搜索框输入 `莫吉托`（URL 变为 `#/recommend?q=莫吉托`）

**输出**：切换到纵向列表，共 112 条候选（逐字匹配把含「莫/吉/托」任一字的结果也捞了进来），但**排在最前面的都是酒名里含完整「莫吉托」的**：

```

草莓莫吉托（Strawberry Mojito）
青柠莫吉托（Lime Mojito）
白色圣诞莫吉托（White Christmas Mojito）
蓝莓莫吉托（Blueberry Mojito）
…
```

只有单字命中的（如「莫兰吉托 Moranguito」）会排在完整命中的后面。

### 例 2：用「我的材料」找能做的酒

**输入**（下面三种写法都支持，分两次录入）：

```
第 1 次：可乐 / 青柠汁     → 用 / 拆成「可乐」「青柠汁」
第 2 次：lime, mint        → 英文别名转成「青柠」「薄荷」
（带单位也认：30毫升朗姆酒 → 「朗姆酒」）
```

**输出**：

```
我的材料：可乐 ✕  青柠汁 ✕  青柠 ✕  薄荷 ✕

能做的酒
  材料齐全 (1)     朗普勒薄荷酒（Rumple Minze Shot）  …
  还差 1 样 (33)   阿玛雷托 …                        还差 阿玛雷托
```

匹配是**双向包含**的：录「朗姆酒」也能命中需要「白朗姆酒」的配方；冰块和水不计入缺料。

### 例 3：盲盒筛选与抽取

**输入**：价格档位不点（= 不限）→ `符合条件：1341 款`；点一下「30元内」→ 输出 `符合条件：721 款`（另有 30–80 元 561 款、80 元以上 59 款）。

**输出**：点「🎯 抽一瓶」后，页面下方直接渲染这张卡：

```

气泡 · 含酒精 · 约 38元 · 30–80元 · 甜 · 苦
配料 / 做法 / 我的评价
[＋ 加入酒柜]   [🎲 再来一次]
```

「再来一次」会排除上一次的结果，不会连着抽到同一瓶。

## 项目结构

```
融酒/
├─ index.html              入口，双击即可运行；内含 PWA 的 manifest / 图标 / SW 注册
├─ manifest.webmanifest    PWA 清单：名称、图标、standalone、主题色
├─ sw.js                   Service Worker：外壳预缓存 + 配方图按需缓存
├─ .nojekyll               告诉 GitHub Pages 不要走 Jekyll 处理
├─ icons/                  应用图标（192 / 512 / iOS 180，由 tools/make-icons.js 生成）
├─ css/style.css           全部样式
├─ js/
│  ├─ data.js              配方数据（由 tools/gen-data.js 自动生成，勿手改）
│  ├─ tags.js              语义层：口味标签、价格档位与估算、分区归类、材料名归一
│  ├─ core.js              纯逻辑层：路由解析、筛选、洗牌、随机抽
│  ├─ ui.js                纯渲染层：输出 HTML 字符串（不碰 DOM，可在 Node 里测）
│  ├─ app.js               装配层：state、路由、事件委托
│  └─ store.js             localStorage 读写、备份导入导出
├─ 素材/                   配方原图与 index.zh.json（约 74 MB）
├─ tools/                  数据生成 / 清洗 / 单位换算 / 图标生成等开发脚本
├─ tests/                  node --test 测试用例
└─ PRO.md                  需求与决策记录
```

分层原则：`data.js`（数据）→ `tags.js`（语义）→ `core.js`（逻辑）→ `ui.js`（渲染）→ `app.js`（装配）→ `store.js`（持久化）。`core.js` / `ui.js` / `tags.js` 均不依赖 DOM，因此绝大部分逻辑都能在 Node 里直接测。

## 开发与测试

```bash
# 运行全部测试（零依赖，不需要 npm install）
node --test "tests/*.test.js"

# 重新生成应用图标（改了品牌色或图标造型后跑一次）
node tools/make-icons.js

# 本地预览 PWA（Service Worker 需要 http/https 才生效）
npx serve .
```

改了 `css/` / `js/` / `index.html` 后，记得把 `sw.js` 里的 `VERSION` 加一（如 `rongjiu-v2`），
旧缓存会在 activate 阶段被清掉，用户下次打开就是新版本。

## 已知限制

- **数据存在浏览器本地**：手动清空浏览器数据会丢失个人数据，请用「导出备份」兜底。
- **换域名 = 换数据**：`localStorage` 按域名隔离，`localhost`、Pages 地址、`file://` 三者各自独立，跨环境要用「导出 / 导入备份」搬。
- **配方是本地静态数据**：新增配方只存在本机，不会同步给别人。
- **价格是规则估算**（按配料关键词累加），仅用于盲盒分档参考，不是真实成本。
- **不提供**账号、云同步、社交分享、库存数量管理。
- 图片较多（约 74 MB），本地使用请确保 `素材/` 目录完整；线上访问时图片按需加载。
- 离线缓存只覆盖**已经看过**的配方图；没打开过的图在离线时占位显示。
